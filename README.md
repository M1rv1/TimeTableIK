# Расписание IK-Study
*Создана программа для составления расписания, которая принимает входные данные через два txt документа и преобразует их в таблицу excel с готовым варинтом учебной нагрузки*
***
### Что такое IK-Study?
IK-Study это достаточно популряные курсы по подготовки школьников к ЕГЭ (физика, математика, информатика), к ОГЭ (тот же набор предметов) и к вступительным испытаниям по математике в лучше школы Санкт-Петербурга

### Какова специфика программы?
Создание расписание здесь не такое сложное, как в случае обычной школы: всего 3 кабинета, максимум 30 разных групп, учителей в среднем 10. Но не все так просто! Варианты для времени занятий нужно учитывать по предпочтениням самих школьников- это реализуется по средствам ввода данных, что сильно сокращает время создвния расписания, так как именно учет предпочтений всех школьников из этих всех групп и забирает часы в предположительно простой ситуации

### Как работает программа?
Сначала читаются все данные, которые ввел пользователь. Далее производиться частотный анализ мест, выбранные школьниками. Дальше при помощи модуля Google.Ortools начинается перебор всевозможных мест, где могут быть уроки. А потом в эти возможные места начинают вставляться уроки, которые попадают под некоторые ограничения. Но помимо этого так расписание оптимизируется: выбирается наиболее выбираемое время для уроков, а учителям выбирается расписание с наименьшим количеством окон в рабочем графике

### Учитываемые ограничения
1. *Должен выполняться учебный план* - если два часа в неделю, то ни больше, ни меньше
2. *Ограничения на параллельные группы в кабинетах* - так как кабинеты не одинакового размера, а они идут по возрастанию посадки, то нужно учитвать, что, например, не может быть две большие группы, так как одна из них просто не поместиться оставшемся кабинете
3. *Ограничения самих учителей*
4. *Учитель не может вести два урока одноврменно*

### Обязательные библиотеки
В программе используется две внешние библиотеки, которые нужно скачать для работы кода
**Следует написать в консоль**:
1. pip install openpyxl
2. pip install ortools

1. В репозитории помимо самой программы также есть входные данные для учебного года 2026/2027 (их можно использовать в том числе для примера входных данных)
